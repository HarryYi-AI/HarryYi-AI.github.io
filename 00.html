Quant 面试复习手册 00｜总目录与快速通道

📌 Quant 面试复习手册 · 第 0 篇（总目录）
6 篇主干 + 1 篇补充，完整讲解版。框架参考 OpenQuant《Quant Interview Study Guide》+ 主流面试考点清单 + Mr.RC 两篇 X 长文深化。
定位：面试前快速查看 + 日常系统学习。每篇末尾都有「自测清单」和「30 秒速查总表」。

一、目录

篇 篇目 覆盖考点 核心必背产出

02 随机微积分与股价模型 布朗运动、SDE、伊藤积分、二次变差、伊藤引理证明骨架、GBM 求解 √t 标度律、$(dW)^2=dt$ 证明、GBM 精确解

二、面试前快速通道（按剩余时间）

只剩 30 分钟：只看每篇末尾的「30 秒速查总表」（7 张表过一遍），卡壳处回翻对应小节。

只剩一晚（2.5–3.5 小时）：每篇过一遍正文 + 自测清单逐条完成（约 20 分钟/篇）。优先级：01 → 03 → 02 → 04 → 06 → 05 → 07（概率与定价是出现率最高的两块；07 为补充篇，面预测市场岗必看）。

三个准备日：
- Day 1：01 + 02（数学地基：分布、统计推断、马尔可夫链、伊藤引理、GBM）
- Day 2：03 + 04（定价主线 + 机器学习）
- Day 3：05 + 06 + 07（速查类 + 金融专题 + 预测市场），速查总表抄写一遍

按岗位侧重：

岗位 主攻
Quant Researcher 01、02、03、04、06（统计推断、回归假设、时间序列）
Quant Trader 01、03、06、07（概率反应题、定价直觉、做市与组合、预测市场）
Quant Developer 02、04、05（工程实现、模拟代码、矩阵计算）
预测市场 / 加密交易 06 做市部分 + 07 全篇

三、跨篇概念索引（一条线串起七篇）

$$ \boxed{ \underbrace{\text{股价模型}}_{\text{02}} \xrightarrow{\ \text{伊藤引理}\ } \underbrace{\text{函数的动态}}_{\text{02}} \xrightarrow{\ \text{复制与无套利}\ } \underbrace{\text{定价方程}}_{\text{03}} \xrightarrow{\ \text{风险中性期望}\ } \underbrace{\text{BSM 公式}}_{\text{03}} } $$

高频交叉考点（容易被连环追问的主线）：

  • √t 标度律（02）→ 波动率年化 → $SE(\hat\mu)=\sigma/\sqrt T$（02）→ MVO 估计误差 → BL 收缩 / 半凯利（06）
  • 二次变差（02）→ 伊藤修正项 → $-\frac12\sigma^2$（02）→ 对数正态均值 vs 中位数（02）
  • 指数鞅（02）→ 折现价是 Q-鞅（03）→ 赌徒破产指数鞅法（01）→ logit 空间鞅锁定漂移（07）
  • 赌徒破产（01）→ 生存 vs 期望 → Kelly 公式 / 半凯利（06）
  • Φ(d₂)=Q 实值概率（03）→ 数字期权定价（03）→ 预测市场合约（07）
  • HML 价值因子（06）→ EP/BP 低估值因子族
  • 做市逆向选择（06）→ 价差作为逆向选择补偿 → CLOB 下做市商是生命线（07）
  • MLE 校准（01）→ GARCH/t 分布拟合（06）→ Kalman/EM 参数提取（07）
  • 多重比较（01）→ 回测过拟合 → 换手率与交易成本（06）
