本篇覆盖：线性回归（Gauss-Markov、正则化）→ 分类（模型与指标）→ 树方法 → 神经网络 → LLM 在量化中的应用。

一、线性回归

1.1 模型与 OLS

$$ Y=\beta_0+\sum_{i=1}^p\beta_iX_i+\epsilon $$

OLS 最小化 $RSS=\sum(y_i-\hat y_i)^2$：

$$ \hat\beta=(\mathbf X^\intercal\mathbf X)^{-1}\mathbf X^\intercal\mathbf y,\qquad \mathrm{Var}(\hat\beta)=(\mathbf X^\intercal\mathbf X)^{-1}\sigma^2,\qquad \hat\sigma^2=\frac{RSS}{m-p-1} $$

1.2 Gauss-Markov 五大假设 ⭐（高频考点）

满足时 OLS 是 BLUE（最优线性无偏估计）；再加 $\epsilon\sim N(0,\sigma^2)$ 则同时是 MLE：

假设 内容 金融中的典型违背
1 线性 对参数线性 模型误设
2 严格外生性 $E[\epsilon_i\mid\mathbf X]=0$ 内生性（遗漏变量、联立性）→ 有偏且不一致，最致命
3 无多重共线性 $\mathbf X^\intercal\mathbf X$ 可逆 标准误膨胀、系数不稳
4 同方差 $\mathrm{Var}(\epsilon_i\mid\mathbf X)=\sigma^2$ 异方差（金融常态）：系数仍无偏，标准错误 → 推断失效
5 无自相关 $\mathrm{Cov}(\epsilon_i,\epsilon_j\mid\mathbf X)=0$ 自相关（时序常态）：同上

修正：异方差/自相关不改系数只错标准误 → White（HC）/ Newey-West 稳健标准误。

📌 呼应：BLUE 是"无偏约束下的方差最优"；Ridge/Lasso 等有偏方法靠偏差换方差（对应 MMSE 思想）。

1.3 模型评估与推断

指标 公式 直觉
$R^2$ $1-\frac{RSS}{TSS}$ X 解释 Y 方差的比例；金融里低 $R^2$ 是常态
调整 $R^2$ $1-\frac{RSS/(m-p-1)}{TSS/(m-1)}$ 惩罚无关变量
t 统计量 $\hat\beta_i/SE(\hat\beta_i)$ 单系数显著性
F 统计量 $\frac{(TSS-RSS)/p}{RSS/(m-p-1)}$ 模型整体显著性

1.4 正则化（收缩）

方法 罚项 效果
Ridge $\lambda\sum\beta_j^2$（L2） 全体系数收缩不为 0；专治多重共线性
Lasso $\lambda\sum\lvert\beta_j\rvert$（L1） 部分系数精确为 0；特征筛选，稀疏模型

1.5 偏差-方差分解（ML 第一性原理）

$$ E[(Y-\hat f(x))^2]=\text{不可约误差}+\text{Bias}^2[\hat f]+\text{Var}[\hat f] $$

复杂模型低偏差高方差（过拟合）；简单模型高偏差低方差（欠拟合）；正则化找平衡。

💡 "五假设 → BLUE；+正态 → MLE；异方差/自相关只错标准误；Ridge 保维度、Lasso 砍维度。"

二、分类

2.1 四大核心模型

① 逻辑回归（判别模型）：sigmoid 映射，logit 线性，MLE 估计，线性边界：

$$ P(Y=1\mid\mathbf x)=\frac{1}{1+e^{-(\beta_0+\mathbf x^\intercal\boldsymbol\beta)}},\qquad \ln\frac{P(Y=1)}{P(Y=0)}=\beta_0+\mathbf x^\intercal\boldsymbol\beta $$

② 判别分析（生成模型）：先建模 $f_k(\mathbf x)=P(\mathbf X=\mathbf x\mid Y=k)$，贝叶斯反推后验：

  • LDA：各类共享协方差矩阵 → 线性边界
  • QDA：各类各自协方差矩阵 → 二次边界

③ k-NN（非参数）：k 小 → 高方差过拟合；k 大 → 高偏差；高维遇维度灾难。

④ 朴素贝叶斯（生成模型）：特征条件独立假设 $f_k(\mathbf x)=\prod_jP(X_j=x_j\mid Y=k)$；文本分类利器。

💡 "判别直接算 P(Y|X)，生成先算 P(X|Y) 再贝叶斯反推。"

2.2 性能指标（不平衡数据不能只看准确率）

指标 公式 何时关键
Accuracy $\frac{TP+TN}{\text{总数}}$ 1% 违约率下全猜"不违约"也有 99%——误导
Precision $\frac{TP}{TP+FP}$ 误报代价高（假交易信号）
Recall $\frac{TP}{TP+FN}$ 漏报代价高（漏掉违约）
F1 P 与 R 的调和平均 两者都重要

ROC / AUC：TPR 对 FPR 曲线；AUC = 随机正样本排在随机负样本前的概率（1.0 完美 / 0.5 瞎猜），对不平衡数据稳健。

三、树方法

3.1 单棵决策树

分裂准则：分类用基尼/熵（最大化纯度提升），回归用 RSS/MSE。优点：白盒、天然非线性；缺点：高方差、易过拟合。

3.2 三大集成

① Bagging（降方差）：B 个 bootstrap 样本各训一棵不剪枝树，平均/投票。OOB 误差：每树只用约 2/3 数据，剩下 1/3 免费验证。

② 随机森林 = Bagging + 特征随机化（去相关）：每次分裂只在随机 $m$ 个特征中挑（分类 $m=\sqrt p$，回归 $m=p/3$）；附赠特征重要性。

③ Boosting（序贯降偏差）：每轮对残差训练新树，小学习率缩放；代表 AdaBoost、GBM、XGBoost、LightGBM。精度更高但更易过拟合。

💡 "Bagging 并行降方差，Boosting 串行降偏差；RF 的随机是为了让树互相不熟。"

四、神经网络

4.1 结构与前向传播

$$ \mathbf h^{(l)}=f^{(l)}(\mathbf W^{(l)}\mathbf h^{(l-1)}+\mathbf b^{(l)}) $$

万能近似定理：单隐层 + 非线性激活可逼近任意连续函数。

4.2 激活函数

函数 公式 用途
Sigmoid $\frac{1}{1+e^{-z}}$ 二分类输出；梯度消失
ReLU $\max(0,z)$ 隐藏层首选，解决梯度消失
Softmax $\frac{e^{z_i}}{\sum_j e^{z_j}}$ 多分类输出
Tanh 零中心 (−1,1) 常优于 Sigmoid

4.3 训练与正则化

  • 损失：回归 MSE，分类交叉熵；优化：反向传播（链式法则回传梯度）+ SGD
  • Dropout：随机屏蔽神经元防共适应；早停：验证集性能开始退化就停

4.4 金融架构选型

架构 数据 应用
FNN 表格（截面特征） 信用评分、因子筛选
RNN/LSTM/GRU 时间序列 高频交易、波动率预测
CNN 图像类（订单簿热力图、卫星图） 微观结构模式
自编码器 高维数据 降维、异常检测

五、大语言模型（LLM）

5.1 架构与训练

  • Transformer + 自注意力：动态加权序列上下文，捕捉长距离依赖
  • Encoder-Decoder（BERT 类，理解任务）vs Decoder-Only（GPT 系，生成任务）
  • 四阶段：预训练 → 领域预训练（金融 LLM：BloombergGPT、FinGPT）→ 有监督微调 → RLHF（对齐，可靠 Agent）

5.2 量化中的两大角色

角色一：预测器（把非结构化数据变成信号）

  1. 情绪提取：FinBERT embedding 喂分类器；prompt GPT 级模型判新闻多空——控制传统因子后仍具预测力
  2. 因子生成：LLM 当"因子 Agent"构想新因子并生成代码；抽取公司/事件关系构建知识图谱

角色二：智能体：中心 LLM（推理规划）+ 工具（数据 API、求解器、下单接口）；多 Agent 模拟交易台（分析师/PM 协作，推理链可解释）；覆盖 数据 → 信号 → 组合优化 → 执行 全流程

5.3 四大挑战与对策

挑战 对策
幻觉 RAG（实时文档接地）
非平稳性 持续预训练 + 高频微调
延迟 模型压缩；只做低频任务
数据泄漏 私有/领域专用 LLM

💡 "低频看它当预测器和研究员，高频它上不了场。"

七、30 秒速查总表

考点 一句话
OLS $\hat\beta=(X'X)^{-1}X'y$；五假设 → BLUE，+正态 → MLE
稳健标准误 White（异方差）/ Newey-West（自相关），只修 SE 不修系数
正则化 Ridge 保维度（L2），Lasso 砍维度（L1）
偏差方差 EPE = 不可约 + Bias² + Var
分类指标 不平衡看 P/R/F1/AUC，别信 Accuracy
树 Bagging 并行降方差，Boosting 串行降偏差，RF = Bagging+特征随机
NN 隐藏层 ReLU，分类输出 Softmax，防过拟合 Dropout+早停
