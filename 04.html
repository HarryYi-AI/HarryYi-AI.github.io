Quant 面试复习手册 04｜机器学习与深度学习（完整讲解版）：回归、分类、树、NN、LLM

📌 Quant 面试复习手册 · 第 4 篇 / 共 7 篇
本篇按"为什么有效 → 怎么用 → 什么时候失效"的逻辑讲清每个模型。金融数据的特点贯穿全篇：信噪比极低、非平稳、易过拟合——所以每个方法都要问"它对噪声做了什么假设"。
覆盖：线性回归（OLS/Gauss-Markov/正则化）→ 分类模型与指标 → 树方法 → 神经网络 → LLM。

1. 线性回归：一切模型的基准线

1.1 模型与 OLS 解的推导

模型：

$$ Y=\beta_0+\sum_{i=1}^p\beta_iX_i+\epsilon $$

OLS 的目标是最小化残差平方和 $RSS=\sum_{i=1}^m(y_i-\hat y_i)^2$。矩阵形式对 β 求导：

$$ RSS=(\mathbf y-\mathbf X\boldsymbol\beta)^\intercal(\mathbf y-\mathbf X\boldsymbol\beta)\ \Rightarrow\ \hat\beta=(\mathbf X^\intercal\mathbf X)^{-1}\mathbf X^\intercal\mathbf y $$

系数协方差矩阵 $\mathrm{Var}(\hat\beta)=(\mathbf X^\intercal\mathbf X)^{-1}\sigma^2$，误差方差估计 $\hat\sigma^2=\frac{RSS}{m-p-1}$（自由度要扣掉 p+1 个被估参数）。

几何解释（面试加分）：拟合值 $\hat{\mathbf y}$ 是 $\mathbf y$ 在 X 列空间上的投影，残差与所有回归量正交——OLS 就是"把 y 往特征张成的子空间上投影"。

1.2 ★ Gauss–Markov 五大假设（出现率最高的考点）

满足全部五条时 OLS 是 BLUE（最优线性无偏估计）；再加 $\epsilon\sim N(0,\sigma^2)$ 则同时是 MLE。逐条列出假设与金融中的典型违背：

假设 内容 金融中的典型违背 后果
1 线性 模型对参数线性 非线性关系被忽略 模型误设
2 严格外生性 $E[\epsilon_i\mid\mathbf X]=0$ 内生性：遗漏变量、联立性 有偏且不一致——最致命
3 无多重共线性 $\mathbf X^\intercal\mathbf X$ 可逆 因子间高度相关（如动量与反转） 标准误膨胀、系数不稳
4 同方差 误差方差恒定 异方差：波动率聚集（高波动期误差大） 系数仍无偏，标准错误 → t 检验失效
5 无自相关 $\mathrm{Cov}(\epsilon_i,\epsilon_j)=0$ 自相关：收益序列相关（时序数据常态） 同上

关键结论（必背）：异方差与自相关不使系数有偏，只使标准误错误 → 系数点估计还能用，但 t 检验/置信区间全废。修正用稳健标准误：异方差用 White（HC），自相关用 Newey–West（两者可叠加）。只修 SE，不改系数。

【考点】为什么金融里 R² 很低是常态：收益的不可预测部分（噪声）占绝对主导，横截面回归 R² 在 1%~5% 就已可用——低 R² 不是模型错，是市场难。

1.3 模型评估与推断

指标 公式 解读
$R^2$ $1-\frac{RSS}{TSS}$ X 解释 Y 方差的比例
调整 $R^2$ $1-\frac{RSS/(m-p-1)}{TSS/(m-1)}$ 惩罚无关变量，跨模型比较用
t 统计量 $\hat\beta_i/SE(\hat\beta_i)$ 单系数显著性，自由度 $m-p-1$
F 统计量 $\frac{(TSS-RSS)/p}{RSS/(m-p-1)}$ 模型整体显著性（所有斜率同时为 0）

1.4 正则化：用偏差换方差

方法 罚项 目标函数 效果
Ridge $\lambda\sum\beta_j^2$（L2） $RSS+\lambda\sum\beta_j^2$ 系数全体收缩但不为 0；专治多重共线性（有闭式解）
Lasso $\lambda\sum\lvert\beta_j\rvert$（L1） $RSS+\lambda\sum\lvert\beta_j\rvert$ 部分系数精确压到 0；自动特征筛选，适合稀疏世界

本质（对应第 1 篇 MLE/BLUE）：正则化 = 给 OLS 加先验/约束，牺牲一点偏差换取方差大幅下降——与统计推断篇"多重比较"的教训一致：金融数据信噪比低，不加约束的 OLS 会把噪声拟合成信号。

1.5 ★ 偏差-方差分解（ML 第一性原理）

$$ E[(Y-\hat f(x))^2]=\underbrace{\sigma^2}_{\text{不可约误差}}+\underbrace{\mathrm{Bias}^2[\hat f(x)]}_{\text{模型太简单}}+\underbrace{\mathrm{Var}[\hat f(x)]}_{\text{模型太敏感}} $$

  • 偏差：用简单模型逼近真实关系的系统性误差
  • 方差：模型对训练数据扰动的敏感度（换个样本结果大变）
  • 不可约误差：噪声本身，任何模型都去不掉
偏差 方差 风险
简单模型（OLS 少特征） 高 低 欠拟合
复杂模型（深树/多特征） 低 高 过拟合

正则化、交叉验证、早停、剪枝——全部是这条分解式的工程化。

【记忆】"五假设 → BLUE；加正态 → MLE；异方差/自相关只错标准误（Newey-West 修）；Ridge 保维度、Lasso 砍维度；一切 = 偏差方差权衡。"

2. 分类：预测离散结果

2.1 两大流派

判别模型：直接建模 $P(Y\mid X)$（逻辑回归）。
生成模型：先建模每类的 $P(X\mid Y=k)$，再用贝叶斯反推 $P(Y=k\mid X)$（LDA/QDA/朴素贝叶斯）。

模型 核心机制 决策边界 估计方法
逻辑回归 sigmoid 映射，logit 线性 线性 MLE
LDA 各类共享协方差的高斯建模 线性 类均值+协方差
QDA 各类各自协方差 二次 同上
k-NN 近邻投票 非参数、局部 无训练
朴素贝叶斯 特征条件独立 由似然决定 频率计数

逻辑回归细节（面试常问）：

$$ P(Y=1\mid\mathbf x)=\frac{1}{1+e^{-(\beta_0+\mathbf x^\intercal\boldsymbol\beta)}},\qquad \ln\frac{P(Y=1)}{P(Y=0)}=\beta_0+\mathbf x^\intercal\boldsymbol\beta $$

  • 对数几率（logit）对特征线性——系数可直接解读为"特征变动 1 单位，对数赔率变化 β"
  • 无闭式解，用 MLE 数值优化
  • 与线性回归的区别：输出被压到 (0,1) 且损失是对数似然而非平方误差

朴素贝叶斯的"朴素"：假设给定类别后特征条件独立——强假设，但文本分类（词袋模型天然近似独立）表现出奇地好。

k-NN 要点：k 小 → 决策边界复杂 → 高方差过拟合；k 大 → 平滑 → 高偏差。高维数据距离失效（维度灾难：所有点距离趋同）。

2.2 性能指标：不平衡数据的正确姿势

金融场景天然不平衡：违约率 1%、信号触发率 5%。混淆矩阵四格 TP/FP/FN/TN：

指标 公式 回答的问题 什么时候看它
Accuracy (TP+TN)/总数 整体猜对比例 不平衡时误导（全猜"不违约"也有 99%）
Precision TP/(TP+FP) 预测为正中多少是真的 误报代价高（假信号浪费交易成本）
Recall TP/(TP+FN) 真正例抓住多少 漏报代价高（漏掉违约/欺诈）
F1 P 与 R 调和平均 两者平衡 需要单一指标比较模型时

ROC 与 AUC：ROC 曲线 = 遍历所有阈值，画 TPR（召回）对 FPR（假阳性率）。AUC = 随机取一正一负样本，模型给正样本更高分的概率——1.0 完美、0.5 等于瞎猜，且与阈值和类别比例无关，是不平衡数据的稳健指标。

【易错】类别极不平衡时，Accuracy 会撒谎：99% 不违约的数据上全猜"不违约"就有 99% 准确率，但模型毫无价值。

3. 树方法：非线性与交互的主力

3.1 单棵决策树

递归选择特征与切分点，让子节点更"纯"：分类用基尼指数/熵（不纯度下降最大），回归用 RSS/MSE（子节点内方差最小）。

优点：可解释、天然处理非线性与交互、不要求数值化。缺点：高方差——数据微小扰动就长出完全不同的树，容易过拟合。

3.2 ★ 集成方法：三种降误差的策略

① Bagging（Bootstrap Aggregating）——并行降方差

从 m 个方差为 σ²、两两相关 ρ 的树取平均：

$$ \mathrm{Var}(\bar f)=\rho\sigma^2+\frac{1-\rho}{B}\sigma^2 $$

B→∞ 只能消掉第二项，ρ 不降则极限仍在——这就是为什么需要随机森林。

② 随机森林 = Bagging + 特征随机化（压 ρ）

每次分裂只在随机 m 个特征里挑（分类 $m=\sqrt p$、回归 $m=p/3$），逼树之间"互相不熟"降低 ρ。附赠特征重要性（节点不纯度下降的平均量）。

③ Boosting——串行降偏差

每轮用残差（或伪残差）训练一棵小树，以小学习率 λ 缩放叠加：逐步修正前面的错误。代表：AdaBoost、GBM、XGBoost、LightGBM。精度通常更高，但学习率过大或树过多会过拟合。

OOB（袋外）误差：每棵 Bootstrap 树约 1/3 样本没被抽到（袋外样本），直接用它验证——免费的内建交叉验证。

【记忆】"Bagging 并行降方差，Boosting 串行降偏差；RF = Bagging + 特征随机（压 ρ）；XGBoost/LightGBM 是 Boosting 的现代工业实现。"

4. 神经网络

4.1 结构与前向传播

$$ \mathbf h^{(l)}=f^{(l)}(\mathbf W^{(l)}\mathbf h^{(l-1)}+\mathbf b^{(l)}) $$

每层 = 线性变换 + 非线性激活。万能近似定理：单隐层 + 非线性激活即可任意精度逼近连续函数——理论保证，但深度网络在优化与样本效率上更实用。

4.2 激活函数

函数 公式 用途 注意
Sigmoid $1/(1+e^{-z})$ 二分类输出 两端饱和 → 梯度消失
ReLU $\max(0,z)$ 隐藏层默认 计算便宜、缓解梯度消失
Softmax $e^{z_i}/\sum_j e^{z_j}$ 多分类输出 输出和为 1
Tanh 零中心 (−1,1) 隐藏层（旧） 零中心优于 Sigmoid

4.3 训练与正则化

  • 损失：回归用 MSE，分类用交叉熵（$-\sum y\ln\hat y$）
  • 反向传播：链式法则从输出层逐层回传梯度，SGD 及变体更新
  • Dropout：训练时随机丢弃神经元，防共适应，等价于隐式集成
  • 早停：验证集损失开始回升就停——直接对应偏差-方差权衡里的"停在方差开始涨的点"

4.4 金融场景的架构选型

架构 适配数据 金融应用
FNN 前馈 表格（截面因子） 因子合成、信用评分
RNN/LSTM/GRU 时间序列 波动率预测、序列信号
CNN 局部模式（订单簿热力图、K 线图） 微观结构形态识别
自编码器 高维数据 降维、异常检测（市场错位）

5. 大语言模型（LLM）

5.1 架构与训练范式

  • Transformer + 自注意力：每个 token 动态加权全序列上下文，解决长距离依赖
  • Encoder-Decoder（BERT 类，理解任务）vs Decoder-Only（GPT 系，生成任务）
  • 四阶段训练：预训练（通用语料）→ 领域预训练（金融语料 → BloombergGPT/FinGPT 类）→ 有监督微调（定向任务）→ RLHF（对齐人类偏好，产出可靠助手）

5.2 量化中的两大角色

角色一：预测器（把非结构化数据变成信号）

  1. 情绪提取：FinBERT embedding 喂分类器；直接 prompt 大模型判断新闻多空——学术结果：控制传统因子后仍具预测力
  2. 因子生成：让 LLM 基于金融理论构想新因子并生成计算代码；从文本抽取公司/事件关系构建知识图谱

角色二：Agent（自主决策）

中心 LLM 负责推理规划 + 外部工具（数据 API、优化求解器、下单接口）；多 Agent 模拟交易台分工协作（基本面/技术面/风控），推理链天然可解释；可覆盖"数据 → 信号 → 组合优化 → 执行"全链路。

5.3 四大挑战与对策

挑战 说明 对策
幻觉 编造事实，金融里致命 RAG：检索实时文档给回答接地
非平稳 市场分布漂移 持续预训练 + 滚动微调
延迟 推理慢 模型压缩；只用于低频任务
数据泄漏 训练语料"背过"历史 私有/领域专用模型

【记忆】"LLM 在量化里的定位：低频信息处理与研究员，高频执行上不了场。"

6. 自测清单（必须掌握的考点）

  • ☐ OLS 矩阵解推导；Gauss-Markov 五假设各自违背后果
  • ☐ 异方差/自相关"不改系数改标准误"；White/Newey-West
  • ☐ Ridge 与 Lasso 的罚项、几何直觉、适用场景
  • ☐ 偏差-方差分解公式；正则化 = 偏差换方差
  • ☐ 判别 vs 生成模型；LDA/QDA 边界差异
  • ☐ 不平衡数据看 Precision/Recall/F1/AUC；Accuracy 悖论
  • ☐ Bagging 降方差公式（ρσ² + (1−ρ)σ²/B）；RF 为什么压 ρ；Boosting 降偏差
  • ☐ ReLU 解决梯度消失；Dropout/早停对应偏差-方差
  • ☐ LLM 四阶段训练 + 四大挑战对策
