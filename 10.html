1. 数据工程：每个细节都是一个面试题

1.1 财务数据的 point-in-time（FF3 notebook 最核心的教训）

财务数据的复杂性来自三个时间：报表数据所处的时间（endDate）、报表报告的时间（endDateRep）、报表修改的时间（publishDate）。

【易错】很多研究都采用了"事后修改"过的数据（例如 GDP 数据）。如果做的是预测性质的研究，站在 t 时刻，是不可能知道 t+5 时刻会修改 t−1 时刻的数据的——很多研究因此站不住脚。

两种合理处理：① 预留充足时间，保证使用时数据已可得（不一定最新）；② point-in-time——无论何时使用，只用当时已发布的最新版本。

BM ratio 的 FF (1993) 原文构造：

  • 每年 12 月底的 book equity ÷ 12 月最后一个交易日的 mktcap = BM
  • 这个 BM 作为下一年 7 月至下下一年 6 月的排序变量（错峰 6 个月是为了避免价格变动本身带来的市值-收益相关性）

实现细节：publishDate 与 tradeDate merge 时要 outer（publishDate 可能是非交易日，merge 后 tradeDate 为空的填成 publishDate 便于排序），再按 secID + tradeDate sort，用 ffill 让每条财报数据"一直有效到下一份发布"。月份错峰映射：2017 年 12 月的 BM 分组对应 2018:07–2019:06 的收益（ret_year − 1，1–6 月再 −1）。

1.2 停牌的三种处理逻辑（不能一刀切）

场景 停牌处理 原因
计算动量 可以不处理 停牌前后价格算收益率，也是动量的一种衡量
计算 Beta 必须剔除（不可设 0） 市场收益每天都有，个股停牌设 0 会造成回归大偏差
计算波动率/月收益 必须剔除 设 0 会低估波动；停牌无法交易无法调仓

填充缺失日期的快速技巧（fill_missing 函数）：对每只股票取 start/end → 生成完整日期序列 → 构造 MultiIndex(stk_id, dates) → reindex 扩充原 DataFrame，缺失自动填 NaN——比逐股循环快得多。

1.3 其他工程细节

  • ST 股剔除；新股上市首月不参与（找到每只股票上市日期与样本起点比较）
  • 排序用上月末市值：t 月末市值作为 t+1 月的分组标准（FF 惯例）——避免当月价格变动与收益本身的相关性污染分组
  • 分块下载数据：优矿 API 有调用频率限制，按季度/按年分块 + 捕获截断提示重试

2. 单排实现：按 Beta 分 10 组（完整流程模板）

2.1 分组代码模式（所有单排的通用模板）

q = {f'q{i}': v for i, v in zip(range(1, 10), np.arange(0.1, 1.0, 0.1))}
quantile_df = pd.DataFrame({k: ret_df.groupby('group_month')['Beta252'].quantile(v) for k, v in q.items()})
ret_df_q = pd.merge(ret_df, quantile_df, on='group_month')

portfolios = {}
portfolios['p1'] = ret_df_q.loc[ret_df_q['Beta252'] <= ret_df_q['q1'], cols]
for i in range(2, 10):
    idx = (ret_df_q[f'q{i-1}'] <= ret_df_q['Beta252']) & (ret_df_q['Beta252'] <= ret_df_q[f'q{i}'])
    portfolios[f'p{i}'] = ret_df_q.loc[idx, cols]
portfolios['p10'] = ret_df_q.loc[ret_df_q['Beta252'] >= ret_df_q['q9'], cols]

2.2 组合收益的两种加权

  • 简单平均（EW）：groupby('ret_month')['exret'].mean()
  • 市值加权（VW）：组内市值求和 → 每股 weight = mktcap/mktcapsum → weighted_ret 求和（np.vstack 快速合并各组序列）

2.3 ★ 显著性检验：NW 调整的 t 值

每组月收益序列 y，检验均值是否为 0——用 ols_hac 做常数回归：

reg = ols_hac(y, X=None, maxlags=6)
mean_values[k] = reg.params[0]
t_values[k] = reg.tvalues[0]
# 多空组合 p10−p1 同样处理
y = portfolios_crs_mean['p10'] - portfolios_crs_mean['p1']

技巧：均值 = 常数回归的截距，NW 标准误由 HAC 自动给出（第 9 篇 FM 一节的工程技巧）。

3. ols_hac 精读：向量化 Newey–West（第 6 篇 NW 的代码实现）

W = X * u                      # (T, k)：逐行 = u_t · x_t
S = W.T @ W                    # Lag 0 项：Σ x_t x_t' u_t²
for l in range(1, maxlags + 1):
    weight = 1 - l / (maxlags + 1)         # Bartlett 权重（线性衰减）
    gamma_l = W[l:].T @ W[:-l]             # 所有 t 与 t−l 内积的一步算出
    S += weight * (gamma_l + gamma_l.T)    # 自协方差是对称的
if small_sample:
    S *= T / (T - k)
V = XtX_inv @ S @ XtX_inv      # 三明治协方差
se = np.sqrt(np.diag(V)); t_stat = beta / se

对照第 6 篇 NW 公式 $\hat\sigma^2(\hat\lambda)=\frac1T\sum_{j=-\infty}^{\infty}\mathrm{cov}_T(\hat\lambda_t,\hat\lambda_{t-j})$：Bartlett 权重 $1-\frac{l}{L+1}$（线性衰减）、gamma_l + gamma_l.T 一次矩阵乘法算出所有滞后交叉项（避免逐行循环）、小样本自由度修正 T/(T−k)。这就是你项目 t_NW 的实现原型。

4. ★ A 股单排实证结论（2016:01–2025:02，全部 A 股）

4.1 Beta 单排（按上月末 Beta252 分 10 组）

  • 各组合收益率没有明显区别：CAPM 在中国市场也不成立
  • p1（低 Beta）与 p10（高 Beta）累积收益接近；p2/p9、p3–p8 分层接近
  • 组合特征：p10 高 Beta 组在 2015、2018、2021 前后大起大落；沪深 300 指数的编制正好围绕 p9、p10（指数由高 Beta 股主导）
  • 个股 Beta 观察：上市初期 Beta 时变剧烈（新股特殊交易规则 + 聚光灯效应）；Beta252 比 Beta60/Beta120 稳定

4.2 市值（Size）单排

Size effect 文献链：Banz (1981) 最早发现 → Fama & French (1992) 系统检验 → FF (1993) 构建 SMB 因子 → FF (2012) 全球市场普遍存在。

FF 的市值口径：$MktCap_{i,t}^{FF}=$ t 年 6 月底股价 × 6 月底股本，作为 t 至 t+1 年的分类标准（错峰防相关性）。

A 股结论：收益率随市值增大而减小；早年 p1–p3 显著 >0，2016–2026 期间 >0 但未达统计显著；各组之间 Beta 无显著区别。

4.3 双排（independent sort：市值 2 组 × Beta 3 组）

  • Beta 组内：小盘股平均收益高于大盘股；小盘上涨多、下跌也多
  • 实现：分别按分位分组（市值 0.5、Beta 0.3/0.7）→ 各组 merge 取交集 → 组内算收益

4.4 三种方法结论一致性

单排、双排、FM 回归结论一致：小市值股比大市值股表现更好；不同时间段市值显著性不一样；Beta 在横截面上对收益无明显差异。（呼应第 9 篇：一种方法显著，另一种通常也显著；多法并用是稳健性标准动作。）

5. FM 回归的实现（第 9 篇方法的代码化）

def fm_reg(df):
    df_ = df.dropna()
    if df_.shape[0] < 15:          # 当月截面少于 15 只则跳过
        return None
    reg = LinearRegression().fit(y=df_.loc[:, 'exret'], X=df_.loc[:, ['Beta252', 'size']])
    return np.insert(reg.coef_, 0, reg.intercept_)   # [截距, β系数, size系数]

temp = ret_df_q.groupby('ret_month').apply(fm_reg)
reg_result_df = pd.DataFrame(temp.values.tolist(),
                             index=temp.index,
                             columns=['intercept', 'beta_coef', 'size_coef'])
# 每列做 NW t 检验（同 2.3 的 ols_hac）

Winsorization 前后对比：按月 0.995/0.005 分位缩尾 Beta 与 size 后再做 FM——极端值对截面回归系数的扰动被控制。组内排序需上月末市值（避免当月相关性）。

6. FF3 构建（BM point-in-time + 6 组合）

6.1 六个组合 → SMB/HML

市值 2 组（Small/Big）× BM 3 组（Low/Medium/High，30/40/30）= 6 个组合：

bm1_mktcap1 = SL    bm2_mktcap1 = SM    bm3_mktcap1 = SH
bm1_mktcap2 = BL    bm2_mktcap2 = BM    bm3_mktcap2 = BH
SMB = (SL+SM+SH)/3 − (BL+BM+BH)/3
HML = (SH+BH)/2 − (SL+BL)/2

市场收益 = CAPM 的市场收益。中证 800 = 中证 500 + 沪深 300（大中市值整体）。

6.2 BM 的 A 股实证结论（排序：t 年 7 月–t+1 年 6 月，按 t−1 年 12 月 BM）

  • 月、年平均收益不明显单调（美国的价值溢价在 A 股不稳健）
  • 最大 BM 组（估值最低）与最小 BM 组（估值最高）的市值起伏都很大——BM 效应可能与 market cap 有交互
  • point-in-time 版本：用最新 BM 更新组合带来收益递增，但各组合收益仍不显著；p10−p1 的差距显著为正 ✓

7. ta_test：技术策略的统计检验（White's Reality Check）

7.1 两个技术策略

  • MA 双均线：收盘价上穿 MA30 买入、下穿卖出。两种假设口径：Case 1 当日收盘成交（乐观）；Case 2 次日开盘成交（保守）
  • MACD：DIF = EMA_fast − EMA_slow；金叉（DIF 上穿 DEA）买入、死叉卖出；EMA 递推 $EMA_t=Value_t\cdot\frac{Smoothing}{1+Days}+EMA_{t-1}\cdot(1-\frac{Smoothing}{1+Days})$

7.2 ★ 两种统计检验的缺陷与对策

截面检验（cumulative return 版）的缺陷：累积收益率可能在区间最后一段短期冲高；且累积收益右侧无界、左侧有界（0），分布严重不正态。对策：用日均收益的均值做截面检验（分布好得多）。

★ White's Reality Check（Bootstrap）：

  1. 原始指数收益去均值：过滤牛熊市给随机策略带来的正/负偏误
  2. position return 去均值：Bootstrap 的原假设是"策略期望收益为 0"，以此生成抽样分布
  3. 对 1 只股票测 → 对 300 只股票测：多策略时的多重比较正是 WRC 要解决的问题（呼应第 1 篇 Bonferroni/FDR）
